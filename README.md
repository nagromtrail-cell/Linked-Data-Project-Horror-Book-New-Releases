# Linked-Data-Project-Horror-Book-New-Releases
Linked Data Project for LS 563
This data is a collection of newly released horror books. Books are described by their title, author, publishing date, genre, number of pages, number of editions, subgenre, Goodreads rating, and whether it is in a series. Schema.org is my chosen vocabulary for this project. For my URIs, I plan to use Wikidata for my titles, genres, and series names. VIAF will be used for my authors.
Sample triplet: "The Long Low Whistle" isPartOf "Killer VHS"
