# Linked-Data-Project-Horror-Book-New-Releases
Linked Data Project for LS 563.
This data is a collection of newly released horror books, from November 2025 to May 2026. I chose this dataset because it is relevant to books being released now, and horror is generally my favorite genre to read. I also thought it would be interesting to break down the horror genre into subgenres. The books in my dataset are described by their title, author, publishing date, genre, number of pages, number of editions, subgenre, Goodreads rating, and whether it is in a series. Schema.org is my chosen vocabulary for this project. I originally wanted to use BIBFRAME, but couldn't find a good property for the rating of each of the books. For my URIs, I used Wikidata for my genres and series names. Originally, I also considered "title" as a URI, but I couldn't find any correlated information on Wikidata for my titles, so I left it as a literal. I used VIAF for my authors.
